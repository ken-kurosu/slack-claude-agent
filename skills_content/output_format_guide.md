# 出力の形の決め方

## まず決めること
- *読み手と使い道*: その場で読む → Slack に要点。後で使う・表として扱う → ファイル（CSV/PDF 等）
- *長さ*: Slack の返事は要点 3〜5 行まで。詳細は添付ファイルか Canvas に回し、Slack には要点とリンクだけ書く

## Slack に書く時
- 結論を最初に。根拠や手順は箇条書きで短く
- 太字は `*〜*`、表は使わない（崩れるので箇条書きにする）
- URL は 1 行に 1 つ、単独で書く（折り返されるとコピーできない）

## ファイルで渡す時
- 作業フォルダに保存し、最終回答に保存したパスを書く（自動で Slack に添付される）
- ファイル名は中身が分かる日本語でよい（例: `10月の問い合わせ集計.csv`）
- 数字の出典・集計期間をファイルの先頭か Slack の返事に書く

## 曖昧な依頼の時
- 形式の指定がなければ、上の基準で選んで実行する（確認しない）
- 「資料」とだけ言われたら、まず要点を Slack に返し、必要なら形式を聞く
